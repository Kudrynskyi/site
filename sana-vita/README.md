# Sana Vita Medical — головна сторінка

Статичний сайт медичного центру, зверстаний за макетом Figma «Kudrynskyi · UI v2» (Desktop 1440 + Mobile 360).

- `index.html` — розмітка всіх секцій: утиліті-бар, хедер, hero-слайдер (7 слайдів), пошук, цифри довіри, програми, напрямки, «Як це працює», лікарі, відгуки, форма запису, футер, sticky-CTA на мобільному.
- `styles.css` — токени з Figma (`--sv-color-*`, радіуси, тіні) і адаптив: desktop → tablet (≤1100px) → mobile (≤860px).
- `main.js` — слайдер з автопрокруткою, прогресом і паузою (свайп на мобільному), меню «Ще» та мобільне меню, пошук по програмах/напрямках/лікарях, маска телефону й валідація форми, sticky-CTA.
- `assets/` — іконки (SVG) і фото з макета (оптимізовані JPG).

Без збірки й залежностей: відкрийте `index.html` або роздавайте папку будь-яким статичним сервером.

> Імена лікарів, відгуки, ціни (ХХХХ грн) і номер ліцензії — плейсхолдери з макета, їх треба замінити реальними даними клініки. Форма запису поки не надсилає дані на сервер — лише показує підтвердження.
